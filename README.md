# HungNT 3rd-party: Build Report Tool

Asset gốc: [Build Report Tool (Anomalous Underdog)](https://assetstore.unity.com/packages/tools/utilities/build-report-tool-8162)

## Cài đặt

`Packages/manifest.json`:

```json
"com.hungnt.thirdparty.buildreporttool": "https://github.com/HungNT-UPM/com.hungnt.thirdparty.buildreporttool.git"
```

Hoặc Package Manager → **Add package from git URL...**:

```
https://github.com/HungNT-UPM/com.hungnt.thirdparty.buildreporttool.git
```

## Note

- Giữ nguyên namespace gốc của asset: `BuildReportTool`.
- Đây là Editor tool (asmdef Editor-only sẵn có). Mở cửa sổ qua menu **Window > Show Build Report**.
